Description

This project is a full-stack food delivery service application, featuring separate backend and frontend components. It allows users to browse restaurants, view menus, place orders, and manage deliveries. The application is designed to be scalable and maintainable, leveraging modern web technologies.

Features

•
User authentication (Customer, Restaurant, Driver roles)

•
Browse restaurants and their menus

•
Add/remove items to/from cart

•
Place and manage orders

•
Restaurant dashboard for menu and order management

•
Driver interface for managing incoming deliveries

•
Responsive design for various devices

Technologies Used

Backend

•
Language: TypeScript

•
Framework: Express.js

•
Database: MongoDB (via Mongoose ODM)

•
Authentication: JSON Web Tokens (JWT), bcrypt

•
Other: dotenv, nodemailer, axios, cookie-parser, cors, validator

Frontend

•
Language: TypeScript

•
Framework: React

•
Build Tool: Vite

•
Styling: CSS Modules, Ant Design, Tailwind CSS

•
Routing: React Router DOM

•
Other: Axios, Font Awesome, Day.js
